12. Wi-Fi AP 模式

ESP32 作为热点，其他设备连接它。

混合模式 (Station + AP)

📚 知识扩展

编程知识回顾：

  • NAT（网络地址转换）：当 ESP32 同时工作在 AP 和 Station 模式（APSTA）时，连接 ESP32 AP 的设备可以访问 ESP32，但要访问互联网需要 ESP32 做 NAT 转发。ESP-IDF 提供了 esp_netif 的 NAT 功能，需要额外配置。
  • DHCP 服务器：AP 模式下，ESP32 运行一个 DHCP 服务器，为连接的设备自动分配 IP 地址（默认池为 192.168.4.2-192.168.4.254）。你可以用 esp_netif_dhcps_start() 配置 IP 池。
  • Wi-Fi 安全认证模式：WIFI_AUTH_WPA_WPA2_PSK 表示兼容 WPA 和 WPA2。AP 模式下推荐使用 WPA2（最安全），authmode 设为 WIFI_AUTH_WPA2_PSK。密码至少 8 位。

重点掌握：

  • AP 模式下 ssid_len 可以设置 SSID 长度，或者设为 0 让函数自动计算
  • max_connection = 4 是 ESP32 作为 AP 的最大连接数，不能再高（硬件限制）
  • 如果将 password 设为 NULL 或空字符串，authmode 应设为 WIFI_AUTH_OPEN（开放热点）

编程技巧：

  • AP 模式默认网关 IP 为 192.168.4.1，可以修改 esp_netif_ip_info_t 结构体来改变
  • 使用 esp_wifi_set_config 的 AP 配置中，channel 字段可以指定信道（1-13），如果周围 Wi-Fi 网络太多，选择一个不太拥挤的信道提高稳定性
  • APSTA 模式常用于 IoT 设备配网：先用 AP 模式运行配网页面，用户输入家中 Wi-Fi 密码后，切换到 Station 模式连接路由器
