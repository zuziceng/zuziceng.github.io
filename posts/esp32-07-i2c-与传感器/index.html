7. I2C 与传感器

I2C 使用两根线（SCL + SDA）连接多个设备，每个设备有唯一 7 位地址。ESP32 有两个 I2C 控制器（I2C_NUM_0 / I2C_NUM_1），可作为主机或从机。

📚 知识扩展

编程知识回顾：

  • I2C 协议概要：I2C 使用 SCL（时钟）和 SDA（数据）两根线，每个设备有唯一 7 位地址。主机发送 START 信号 → 发送设备地址 + R/W 位 → 从机应答 ACK → 传输数据 → STOP 信号。(MPU6050_ADDR << 1) | I2C_MASTER_WRITE 这一句将 7 位地址左移 1 位，最低位写 0 表示写操作，这是 I2C 协议规范要求的。
  • C99 指定初始化器：.mode = I2C_MODE_MASTER 是 C99 引入的”指定初始化器（Designated Initializer）“语法，可以只初始化结构体的部分字段，未指定的字段自动归零。这是嵌入式开发中推荐的结构体初始化方式，比按顺序初始化更安全、可读性更好。
  • esp_err_t 错误处理：ESP-IDF 的函数通常返回 esp_err_t 类型，成功返回 ESP_OK（0），失败返回负数错误码。使用 ESP_ERROR_CHECK() 宏在调试时自动打印错误并断言，但发布代码中应做更优雅的错误处理。

重点掌握：

  • 写寄存器：发送 START → 设备地址(W) → 寄存器地址 → 数据 → STOP
  • 读寄存器：发送 START → 设备地址(W) → 寄存器地址 → 重新发送 START → 设备地址(R) → 读取数据 → NACK → STOP（这个”重新发送 START”被称为 Repeated Start）
  • i2c_master_read_byte 的最后一个参数：I2C_MASTER_ACK 告诉从机还要继续读，I2C_MASTER_NACK 告诉从机这是最后一个字节

编程技巧：

  • I2C 设备的 7 位地址通常写在数据手册中，但有些手册给出的是 8 位地址（已经左移过的），需要右移 1 位才是 7 位地址。例如数据手册写 0xD0，实际 7 位地址为 0x68
  • SDA/SCL 需要外部上拉电阻（4.7kΩ 典型值）。ESP32 内部有弱上拉（约 45kΩ），慢速（100kHz）短距离可以用，但推荐外部上拉
  • 使用 idf.py menuconfig → Component config → ESP32-specific → Enable I2C 可以调整 I2C 时序参数，在长距离通信时可能需要降低速率
