2.1 性能优化的核心原则

原则大白话
避免不必要的渲染不要动不动就刷新整个页面，只更新变了的部分
延迟加载用户看到什么就先加载什么，没看到的等看到再说
减少重复计算计算一次然后缓存结果，别每次都重新算
合理使用线程耗时操作不要阻塞主线程

2.2 LazyForEach——鸿蒙列表懒加载组件。英文定义：LazyForEach is a data-driven rendering component that only renders items visible in the current viewport, significantly reducing memory usage for large lists. It is the recommended replacement for ForEach when dealing with more than 100 items. —— 长列表懒加载
