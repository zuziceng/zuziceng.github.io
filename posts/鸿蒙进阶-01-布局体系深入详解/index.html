01-布局体系深入详解

Grid/Flex/自适应布局、alignItems/justifyContent 对齐、宽高约束、响应式适配

2026年7月6日鸿蒙开发-核心进阶2分钟阅读

1.1 布局的核心思维——ArkUI 遵循”容器决定排列方式，组件决定自身大小”原则。英文定义：The parent container defines the layout direction and alignment rules; child components define their own size and constraints.

ArkUI 的布局遵循”容器决定排列方式，组件决定自身大小”的原则。

参考: ArkUI 布局基础

1.2 线性布局：Column / Row

Column（垂直排列）和 Row（水平排列）是最常用的布局容器。

alignItems —— 交叉轴对齐

Column 的 alignItems效果Row 的 alignItems效果
Start靠左Start靠顶
Center居中Center居中
End靠右End靠底

justifyContent —— 主轴分布

值效果
Start从头开始排列
Center居中排列
End从尾开始排列
SpaceBetween两端靠边，中间均匀分布
SpaceAround每个元素左右间距相等
SpaceEvenly所有间距（包括两端）相等

参考: Column | Row

1.3 Grid —— 网格布局

适合相册、商品列表等规则的网格排列：

属性作用示例
columnsTemplate定义列宽模板'1fr 1fr 1fr' 三等分，'100px 1fr' 固定+自适应
rowsTemplate定义行高模板同上
columnsGap列间距8
rowsGap行间距8
fr 单位比例分配剩余空间1fr 2fr 表示第一列占 1/3，第二列占 2/3

参考: Grid

1.4 Flex —— 弹性布局

Flex 是 Column/Row 的底层实现，提供了更灵活的排列控制：

FlexDirection 方向

值效果
Row水平排列（默认）
Column垂直排列
RowReverse水平反向
ColumnReverse垂直反向

FlexWrap 换行

值效果
NoWrap不换行（默认，超出会压缩）
Wrap换行
WrapReverse反向换行

参考: Flex

1.5 宽高约束与权重

属性作用优先度
width / height固定尺寸最高
layoutWeight按比例分配父容器剩余空间次高
constraintSize最大/最小尺寸限制约束边界
aspectRatio宽高比（设为 1 保持正方形）比例约束

📌 HCIP 考点：layoutWeight 和 weight 的区别——layoutWeight 是 ArkUI 的专有属性，分配的是父容器扣除固定尺寸后的剩余空间，与 CSS 的 flex-grow 类似但不等同。
