2. 变量和简单数据类型

2.1 变量

📝 变量（Variable）——存储数据的命名内存位置（Named memory location）。Python 的变量是”标签”（Tag）而非”盒子”（Box）：变量是对对象的引用（Reference），而非对象本身。多个变量可引用同一对象。message = "Hello" 做了两件事：①在内存里创建字符串对象 “Hello”；②将变量名 message 绑定（binding）到该对象的引用上。Python 是动态类型语言——变量无固定类型，可随时指向不同类型对象。与 C/Java 静态类型的核心区别：变量是标签（tag）而非盒子（box）。

2.2 变量的命名规则

  1. 只能包含字母、数字和下划线
  2. 不能以数字开头
  3. 不能包含空格（用下划线分隔）
  4. 不能使用 Python 关键字（if、for、class 等）
  5. 区分大小写（name ≠ Name）

📚 知识扩展

  • 变量即标签：Python 变量不是”盒子”，而是贴在对象上的标签。message = "Hello" 创建字符串对象，再把标签 message 贴上。重新赋值时，只是把标签移到另一个对象上。
  • f-string 是最佳实践：f-string 是字符串格式化的首选方式，比 % 格式化和 .format() 更清晰、更高效。Python 3.12 进一步改进了 f-string，现在可以在表达式中直接使用与外部相同的引号（f"{"inner"}" 合法），嵌套更灵活。
  • 不可变对象：字符串和数字不可变。name.upper() 返回新字符串，不修改原字符串。
  • 浮点数精度：0.1 + 0.2 = 0.30000000000000004 是 IEEE 754 标准的固有限制，不是 Python 的 bug。需要精确计算时用 decimal 模块。
