5.1 什么是 Stage 模型——HarmonyOS 主推的应用模型。英文定义：The Stage model is the recommended application model for HarmonyOS, supporting multi-instance UIAbilities, distributed migration, and componentized architecture.

**Stage 模型——HarmonyOS 主推的应用模型。英文定义：*The Stage model is the recommended application model for HarmonyOS, supporting multi-instance UIAbilities, distributed migration, and componentized architecture.***是鸿蒙 7.0 主推且会长期演进的应用模型。它是应用的”骨架”——定义了应用如何启动、如何运行、如何与其他应用交互。

大白话：Stage 模型——HarmonyOS 主推的应用模型。英文定义：*The Stage model is the recommended application model for HarmonyOS, supporting multi-instance UIAbilities, distributed migration, and componentized architecture.*规定了”你的 App 由哪些独立模块组成，每个模块怎么活、怎么死”。

在 Stage 模型——HarmonyOS 主推的应用模型。英文定义：*The Stage model is the recommended application model for HarmonyOS, supporting multi-instance UIAbilities, distributed migration, and componentized architecture.*中，每个功能模块是一个 UIAbility——Stage 模型中有界面的能力单元。英文定义：*UIAbility is an ability unit with UI in the Stage model, providing lifecycle management, window handling, and intra/inter-device interaction capabilities.*，它们之间相互独立，可以单独启动和销毁。

5.2 UIAbility——Stage 模型中有界面的能力单元。英文定义：UIAbility is an ability unit with UI in the Stage model, providing lifecycle management, window handling, and intra/inter-device interaction capabilities. 是什么

UIAbility——Stage 模型中有界面的能力单元。英文定义：UIAbility is an ability unit with UI in the Stage model, providing lifecycle management, window handling, and intra/inter-device interaction capabilities. 是 Stage 模型——HarmonyOS 主推的应用模型。英文定义：*The Stage model is the recommended application model for HarmonyOS, supporting multi-instance UIAbilities, distributed migration, and componentized architecture.*中具有 UI 界面的能力单元。简单说：你看到的每一个”窗口/页面”，背后都是一个 UIAbility——Stage 模型中有界面的能力单元。英文定义：UIAbility is an ability unit with UI in the Stage model, providing lifecycle management, window handling, and intra/inter-device interaction capabilities.。

一个应用可以有多个 UIAbility——Stage 模型中有界面的能力单元。英文定义：UIAbility is an ability unit with UI in the Stage model, providing lifecycle management, window handling, and intra/inter-device interaction capabilities.：

  • EntryAbility——主入口（App 图标点击后启动的界面）
  • LoginAbility——登录模块
  • PlayerAbility——视频播放模块

5.3 UIAbility——Stage 模型中有界面的能力单元。英文定义：UIAbility is an ability unit with UI in the Stage model, providing lifecycle management, window handling, and intra/inter-device interaction capabilities. 生命周期

生命周期回调触发时机做什么
onCreateAbility 首次创建初始化数据、注册事件
onWindowStageCreate窗口创建加载 UI 页面
onForeground进入前台开始动画、请求数据
onBackground进入后台保存用户数据、释放资源
onWindowStageDestroy窗口销毁清理窗口资源
onDestroyAbility 销毁释放所有资源

📌 HCIA 高频考点：onCreate 只在 Ability 首次创建时调用一次；onForeground/onBackground 在前后台切换时反复调用。
