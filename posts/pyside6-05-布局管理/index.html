5. 布局管理

📝 布局管理器（Layout Manager）——自动管理子控件几何位置的算法组件。专业定义：布局管理器根据容器的可用空间、子控件的 sizePolicy 和约束条件，自动计算每个子控件的位置和大小。当容器尺寸变化时自动重新计算（Responsive Resizing）。4 种基本布局：①QVBoxLayout——垂直排列；②QHBoxLayout——水平排列；③QGridLayout——网格定位，addWidget(w, row, col)；④QStackedLayout——堆叠，一次只显示一个控件。布局可嵌套实现复杂界面。固定套路：创建布局 → addWidget/addLayout → 设给 QWidget → setCentralWidget 放进 QMainWindow。

5.1 四种基本布局

布局类行为适用场景
QVBoxLayout垂直排列（从上到下）表单、列表
QHBoxLayout水平排列（从左到右）工具条、按钮组
QGridLayout网格排列（行/列定位）表格输入、计算器
QStackedLayout堆叠（一次只显示一个）向导页、标签切换

📚 知识扩展

  • QMainWindow 设置布局的固定模式：必须创建中间 QWidget → setLayout(layout) → self.setCentralWidget(widget)。不能直接在 QMainWindow 上设置布局。
  • setContentsMargins(left, top, right, bottom)：控制布局边框到内部控件的间距。四个值独立设置。
  • setSpacing(px)：控件之间的间距。
  • addStretch(int)：在布局中添加弹性空间，将控件推向一侧。数字越大弹性越大。
  • QTabWidget 的标签位置：North（上，默认）、South（下）、West（左）、East（右）。
  • QGridLayout 的 rowSpan 和 colSpan：addWidget(widget, row, col, rowSpan, colSpan) 让控件占多行或多列。

重点掌握

布局核心方法使用要点
QVBoxLayoutaddWidget()从顶到底
QHBoxLayoutaddWidget()从左到右
QGridLayoutaddWidget(w, r, c)指定行列索引
QStackedLayoutsetCurrentIndex(n)配合按钮切换
QTabWidgetaddTab(w, title)内置标签栏，无需手动切换

编程技巧

  • 布局调试技巧：给 Color 控件传入不同颜色，直观看到每个布局占用的空间
  • addStretch() 是一个隐形弹簧：用它可以把控件推到一边
  • 使用 setSizePolicy() 控制控件如何响应布局拉伸：widget.setSizePolicy(QSizePolicy.Expanding, QSizePolicy.Fixed) 水平拉伸、垂直固定
  • 「控件 + 布局」嵌套组合拳：QHBoxLayout 里放表单标签，QVBoxLayout 里放表单行，QGridLayout 做整体排列
  • QTabWidget 的图标：tabs.addTab(widget, QIcon("icon.png"), "Label")
