10.3 异常

📝 异常（Exception）——程序运行时遇到的非正常事件，中断正常指令流。专业定义：异常是继承自 BaseException 类的对象，Python 的异常处理机制将错误处理代码与正常逻辑分离（Separation of concerns）。面试高频： 结构：try→可能出错代码→出错跳到对应 except→没错执行 else→无论如何执行 finally。 关键点：①捕具体异常类型（FileNotFoundError、ValueError），裸露的 except: 会吞掉 KeyboardInterrupt（Ctrl+C 杀不掉）； ②else 在没有异常时执行，区别于放在 try 里的代码——try 里可能隐式抛出其他异常； ③finally 用于清理资源（关闭文件、释放锁），即使 return 了也会执行； ④with 上下文管理器——__enter__ 返回资源，__exit__ 处理清理和异常，比 try-finally 更简洁； ⑤自定义异常——继承 Exception：class MyError(Exception): pass； ⑥raise...from——异常链，保留原始异常上下文：raise newErr from original_err； ⑦assert condition, message——调试断言，python -O 时忽略。

📚 知识扩展

  • pathlib.Path 是处理路径的最佳方式：比 os.path 更简洁、面向对象。Path('dir') / 'file.txt' 比 os.path.join('dir', 'file.txt') 更直观。
  • with 语句：确保文件在使用完后自动关闭，即使发生异常。推荐始终使用。
  • 文件模式：'r' 读取、'w' 写入（覆盖）、'a' 追加、'rb'/'wb' 二进制模式。
  • 异常处理流程：try → except → else → finally。else 在没有异常时执行，finally 总是执行。
