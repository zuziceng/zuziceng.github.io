03-ArkTS 语言基础速览

ArkTS 语言核心概念、变量类型、函数、装饰器、类与模块化，零基础也能看懂

2026年7月6日鸿蒙开发-新手入门2分钟阅读

3.1 ArkTS 是 HarmonyOS 主推的声明式 UI 开发语言。英文定义：ArkTS is a declarative UI development language based on TypeScript, designed for building HarmonyOS applications with static typing and compile-time optimization.

注：HarmonyOS 开发者官网提供中英文双语文档，EN 版本见 https://developer.huawei.com/consumer/en/doc/

ArkTS 是鸿蒙主推的声明式 UI 开发语言，基于 TypeScript 的严格子集。你可以把它理解为”为鸿蒙定制的 TypeScript”——保留了 TS 的类型系统和现代语法，去掉了动态特性以换取编译期优化。

大白话：ArkTS ≈ TypeScript - 动态特性 + 装饰器语法糖

参考: ArkTS 语言概述

学习 ArkTS 需要先学 TypeScript 吗？

不需要。 ArkTS 只用了 TypeScript 的一个安全子集，你只需要掌握本文列出的核心概念就能开始写代码。遇到新语法时边用边学。

3.4 装饰器 —— ArkTS 的核心语法

装饰器（Decorator）——以 @ 符号标记的语法结构，附加元数据或行为到类/属性/方法上。英文定义：A special kind of declaration that can be attached to classes, methods, or properties to modify their behavior. ArkTS uses decorators for component declaration and data binding. 是 ArkTS 最标志性的语法，用 @ 符号标记，给类或属性”附加功能”。

装饰器作用大白话
@Component标记一个 struct 是自定义组件”这是一个 UI 零件”
@Entry标记组件是页面入口”这是应用的一屏”
@State标记变量是”响应式状态""这个数据变了，用到它的UI自动更新”
@Prop子组件从父组件接收数据（单向）“爸爸给你的，你不能改”
@Link子组件与父组件数据双向绑定”你改了我同步，我改了你同步”
