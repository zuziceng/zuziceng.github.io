02-开发环境搭建与DevEco Studio

DevEco Studio 安装配置、模拟器创建、真机调试准备、项目结构解析

2026年7月6日鸿蒙开发-新手入门2分钟阅读

2.1 DevEco Studio 是什么

DevEco Studio 是华为官方提供的鸿蒙应用开发 IDE，基于 IntelliJ IDEA 社区版定制，内置了 ArkTS/JS 的代码提示、编译调试、AI 辅助编码等功能。

官方定义：“DevEco Studio is a one-stop IDE for HarmonyOS application development, providing coding, debugging, compiling, and testing capabilities.”

参考: DevEco Studio 下载

2.2 下载与安装

系统要求

系统版本要求
WindowsWindows 10/11 64 位，8GB+ RAM（推荐 16GB）
macOSmacOS 12+，Apple Silicon 或 Intel 芯片
LinuxUbuntu 20.04+，8GB+ RAM

安装步骤

⚠️ HarmonyOS 6 兼容：SDK Manager 中同时勾选 API 24-25 即可兼容 6.0 设备。当前主力使用 API 26。

代码结构拆解：

代码作用大白话
@Entry标记这个组件是页面入口告诉系统”这是第一屏”
@Component标记这是一个自定义组件这是一个 UI 零件
struct Index定义组件结构给这个 UI 零件起名叫 Index
@State message: string声明状态变量这个数据变了，界面会自动更新
build()描述 UI 长什么样在这里搭界面骨架
Text(this.message)显示文本把 message 显示出来
.fontSize(50)链式调用设置属性设置字体大小，用点号连接

📌 知识点：声明式 UI 的核心思想

你只需要声明”界面应该看起来什么样”，不需要手动更新界面。 当 @State 标记的变量发生变化时，框架自动重新渲染使用了该变量的 UI 部分。 对比传统命令式 UI（拿到 TextView 对象→setText→刷新），声明式 UI 代码更简洁、更不容易出 bug。

2.7 常见问题

问题解决方法
SDK 下载失败检查网络，关闭代理，或手动下载 SDK 包
模拟器无法启动确保电脑开启了虚拟化（VT-x/AMD-V）
真机无法识别检查 USB 线是否支持数据传输，重启 adb 服务
签名失败DevEco Studio → Tools → App Cloud Debug → 自动签名
