8. SPI 总线

SPI 是高速全双工串行通信总线。ESP32 有 2 个 SPI 控制器（SPI2_HOST / SPI3_HOST），支持主机和从机模式，最高时钟可达 80MHz。

8.1 SPI 配置流程

SPI 分为两个配置层次：总线配置（所有设备共享）和 设备配置（每个从设备独立）。

8.3 SPI API 详解

函数原型说明
spi_bus_initializeesp_err_t spi_bus_initialize(spi_host_device_t host, const spi_bus_config_t *bus, spi_dma_chan_t dma_chan)初始化 SPI 总线。dma_chan 传 SPI_DMA_CH_AUTO 自动分配 DMA
spi_bus_add_deviceesp_err_t spi_bus_add_device(spi_host_device_t host, const spi_device_interface_config_t *dev, spi_device_handle_t *handle)注册 SPI 设备，返回设备句柄
spi_device_transmitesp_err_t spi_device_transmit(spi_device_handle_t handle, spi_transaction_t *trans)同步传输（阻塞，利用 DMA 时 CPU 可做其他事）
spi_device_polling_transmitesp_err_t spi_device_polling_transmit(spi_device_handle_t handle, spi_transaction_t *trans)轮询传输（不依赖中断，更快但占 CPU）
spi_bus_remove_deviceesp_err_t spi_bus_remove_device(spi_device_handle_t handle)移除 SPI 设备
spi_bus_freeesp_err_t spi_bus_free(spi_host_device_t host)释放 SPI 总线资源

spi_bus_config_t 结构体：

字段说明
mosi_io_numMOSI 引脚（主机输出，从机输入），-1 表示不使用
miso_io_numMISO 引脚（主机输入，从机输出），-1 表示不使用
sclk_io_numSCLK 时钟引脚
quadwp_io_numQSPI WP 引脚，不用填 -1
quadhd_io_numQSPI HD 引脚，不用填 -1
max_transfer_sz单次传输最大字节数，DMA 传输时建议设为 4096 以上

spi_device_interface_config_t 结构体：

字段说明
modeSPI 模式 0~3，由 CPOL（时钟极性）和 CPHA（时钟相位）决定
clock_speed_hz时钟频率（Hz），ESP32 最高 80MHz
spics_io_numCS 片选引脚编号
queue_size传输队列深度，同时排队传输的最大数量
flagsSPI_DEVICE_TXBIT_LSBFIRST 等标志，默认为 0
pre_cb传输开始前调用的回调函数
post_cb传输完成后调用的回调函数

SPI 模式说明：

模式CPOL（时钟空闲电平）CPHA（采样边沿）
0低第一个边沿（最常用）
1低第二个边沿
2高第一个边沿
3高第二个边沿

spi_transaction_t 关键字段：

字段说明
length传输数据长度（位为单位），如 8 字节 = 64
tx_buffer发送数据缓冲区指针
rx_buffer接收数据缓冲区指针（NULL 表示只发不收）
flagsSPI_TRANS_USE_RXDATA / SPI_TRANS_USE_TXDATA 等
addr地址数据（用于支持地址的 SPI 设备）
cmd命令数据（用于支持命令的 SPI 设备）

📚 知识扩展

编程知识回顾：

  • SPI 与 I2C 对比：SPI 需要 4 根线（MOSI、MISO、SCLK、CS），I2C 只需 2 根线。SPI 是全双工（可以同时发送和接收），I2C 是半双工。SPI 速度更快（可达 80MHz），但没有标准的设备寻址方式（每个设备需要独立的 CS 片选线）。选择依据：速度要求高 → SPI；引脚少、多设备 → I2C。
  • DMA（直接存储器访问）：SPI_DMA_CH_AUTO 启用 DMA 控制器在内存和外设之间直接传输数据，不需要 CPU 逐个搬运字节。对于大块数据传输（如 LCD 刷屏、SD 卡读写），DMA 能极大提高效率。SPI 传输小于 32 字节时 DMA 不一定有优势，因为 DMA 设置开销较大。
  • SPI 模式：由 CPOL（时钟极性）和 CPHA（时钟相位）决定 4 种模式（0/1/2/3）。模式 0（CPOL=0, CPHA=0）是最常用的：空闲时时钟为低，第一个边沿采样数据。使用前要查阅从设备的数据手册确定模式。

重点掌握：

  • quadwp_io_num 和 quadhd_io_num 设为 -1 表示不使用 QSPI（四线 SPI）模式
  • spi_bus_initialize 的 SPI2_HOST 是 SPI 控制器编号（ESP32 有 SPI2 和 SPI3 两个控制器）
  • spi_device_transmit 会阻塞直到传输完成。如果使用 DMA，CPU 在传输期间可以处理其他任务

编程技巧：

  • 如果接收数据不需要（如仅发送命令），rx_buffer 可以设为 NULL
  • SPI 片选（CS）可以手动控制（通过普通 GPIO），不一定要交给 SPI 控制器自动管理。这在一些需要特殊时序的设备中有用
  • 使用 spi_device_polling_transmit 代替 spi_device_transmit，在不使用中断的场景下更轻量
  • 对于大块数据（如 LCD 刷屏 > 4KB），可以分段传输，配合回调函数实现流水线操作
