📚 知识扩展

  • pyside6-uic 生成的代码只是创建控件和设置属性，不包含业务逻辑。你的代码应放在单独的 MainWindow 子类中。
  • promote 自定义控件：在 Designer 中可以将占位 QWidget “提升”（Promote to）为你的自定义控件类，在代码中提供实现。

重点掌握

概念说明
.ui 是 XML 文件描述界面布局和控件属性
pyside6-uic 转换为 .py生成 setupUi() 方法
QUiLoader 动态加载运行时解析 .ui，方便修改界面
信号连接代码中手动连接更可控

编程技巧

  • 不要修改 pyside6-uic 生成的 .py 文件——每次重新生成都会覆盖。业务逻辑写在单独的文件中。
  • 推荐方法一（预转换）：编译期检查 .ui 的有效性，运行时更快。
  • QUiLoader 的局限：某些自定义控件需要提前注册才能加载。
  • 版本管理：.ui 文件是 XML，可以用 Git 跟踪和 diff。
