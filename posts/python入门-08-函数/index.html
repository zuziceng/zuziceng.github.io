8. 函数

8.1 定义函数（含类型提示）

📝 函数（Function）——可复用的代码块（Callable code block），封装特定逻辑。专业定义：函数是接受输入参数、执行语句序列、返回输出值的一等公民对象（First-class object）。面试高频： ①参数传递——位置参数、关键字参数、默认参数（默认值在定义时求值一次，可变对象陷阱 def f(x=[])）、*args（打包位置参数为元组）、**kwargs（打包关键字参数为字典）； ②返回值——不写 return 返回 None，可返回多值（实际是元组）； ③作用域 LEGB 规则——Local → Enclosing（闭包用 nonlocal）→ Global → Built-in； ④闭包（Closure）——内层函数引用外层变量，外层返回后变量仍然存活。常用于装饰器和回调； ⑤装饰器（Decorator）——@decorator 本质是 func = decorator(func) 的语法糖，用于切面编程（日志、鉴权、缓存）； ⑥函数一等公民——可赋值、传参、返回，是高阶函数和函数式编程的基础； ⑦类型提示（3.5+）只是注解，不影响运行，但 mytripe/pyright 可做静态检查； ⑧lambda 表达式——lambda x: x*2 匿名函数，只能写单行表达式。

📚 知识扩展

  • 一等公民：函数是对象，可赋值给变量、作为参数传递、从函数返回。
  • 类型提示不会强制类型：Python 仍是动态类型，类型提示仅用于 IDE 和静态检查工具（mypy、pyright），不会影响运行速度。
  • *args 和 **kwargs：*args 打包位置参数为元组，**kwargs 打包关键字参数为字典。这是实现灵活接口的核心机制。
  • 默认参数要小心：默认值只在函数定义时求值一次。不要用 def f(x=[])，要用 def f(x=None) + 内部判断。
