12. 自定义控件与绘图

12.1 QPainter 基本绘图

12.2 将自定义控件添加到 Qt Designer

  1. 在 Qt Designer 中添加一个普通 QWidget 占位
  2. 右键 → Promote to…
  3. 填写：
    • Promoted class name：CustomWidget（你的类名）
    • Header file：custom_widget（Python 模块名，不含 .py）
  4. 点击 Add → Promote

在代码中实现 custom_widget.py，Qt Designer 生成的 UI 会自动引用你的实现。

📚 知识扩展

  • paintEvent：Qt 在以下时机自动调用：控件首次显示、大小改变、被遮挡后重新暴露、调用 update()。
  • update() 触发重绘：在业务代码中调用 self.update() 通知 Qt 需要重绘，不要直接调用 paintEvent()。
  • QPainter 必须在 paintEvent 中使用：在其他地方创建 QPainter 不会生效。
  • 抗锯齿：painter.setRenderHint(QPainter.Antialiasing) 让图形边缘更平滑。

重点掌握

概念说明
paintEvent重写此方法进行自定义绘制
QPainter绘图工具：点、线、矩形、椭圆、文字
setBrush()设置填充色/图案
setPen()设置线条色/粗细/样式
update()请求重绘（不要直接调用 paintEvent）

编程技巧

  • 绘制性能：频繁重绘的场景（动画、实时数据），避免在 paintEvent 中创建新对象（如 QPen、QBrush），在初始化时创建并复用。
  • QPainter 状态保存与恢复：painter.save() → 修改画笔/画刷 → 绘制 → painter.restore()，避免影响后续绘制。
  • 坐标变换：painter.translate()、painter.rotate()、painter.scale() 实现平移/旋转/缩放。
  • 绘制文字时计算文本宽度：painter.fontMetrics().horizontalAdvance(text) 获取字符串像素宽度，用于对齐。
