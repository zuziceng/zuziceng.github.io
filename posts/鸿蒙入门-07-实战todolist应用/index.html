7.7 知识点回顾

你在实战中用到了……对应的知识点
@State todoList: TodoItem[]状态管理——数组变化自动刷新 UI
List { ForEach(...) }列表渲染——循环生成列表项
Checkbox + .onChange()组件事件——用户交互驱动状态变化
this.todoList = [...this.todoList]触发数组 UI 刷新——展开创建新数组
.decoration({ type: LineThrough })条件样式——完成项加删除线
Navigation + pushPath/pop页面路由——页面间跳转传参
preferences.getPreferences()数据持久化——退出 App 后数据不丢失
aboutToAppear / onPageShow页面生命周期——加载和刷新数据

考点速记

概念一句话记考点
状态刷新修改 @State 变量后，赋新值触发 UI 刷新
数组刷新[...list] 展开创建新数组，框架才能检测到变化
List + ForEach列表渲染标准写法，键值用唯一 id 保证复用效率
Preferences轻量键值对存储，适合保存用户设置和简单数据
生命周期配合aboutToAppear 加载数据，onPageShow 刷新数据
