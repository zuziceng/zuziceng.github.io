1.1 什么是分布式能力

分布式软总线（Distributed Soft Bus）——HarmonyOS 的核心竞争力技术。英文定义：The Distributed Soft Bus is a unified communication infrastructure that enables seamless device discovery, connection, and data sharing across multiple devices. It provides three core capabilities: device discovery, distributed data management, and distributed task scheduling.（Distributed Soft Bus） 是鸿蒙区别于其他 OS 的核心技术。它让多台设备（手机、平板、手表、电视、车机）像一台设备一样协同工作：
