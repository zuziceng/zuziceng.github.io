3.5 Hello World 代码解析

关键点：

  • app_main() 是 ESP-IDF 程序入口（类似 main()）
  • ESP_LOGI / ESP_LOGW / ESP_LOGE 用于日志输出
  • vTaskDelay() 让任务休眠，单位是 tick
  • portTICK_PERIOD_MS 将毫秒转换为 tick

📚 知识扩展

编程知识回顾：

  • static const 的用途：static const char *TAG = "main"; — static 将变量作用域限制在当前文件（避免与其他文件的同名变量冲突），const 使其只读。这是嵌入式开发中常见的”模块标签”写法，用于日志分类。
  • printf 与 ESP_LOG 的区别：printf 是标准 C 库函数，输出直接到 UART 控制台；ESP_LOGI 是 ESP-IDF 封装的日志系统，支持日志级别过滤（I/W/E）、颜色输出、时间戳。生产代码中推荐使用 ESP_LOG*，便于在 menuconfig 中调整日志等级。
  • while(1) 无限循环：嵌入式程序的主循环通常永远不会退出，因为一旦 app_main 返回，程序就结束了。如果没有循环，ESP32 会执行空闲任务，但你的功能代码只会运行一次。

重点掌握：

  • app_main 只执行一次，需要持续运行的功能必须放在 while(1) 或 FreeRTOS 任务中
  • vTaskDelay 是挂起当前任务，而非忙等（不占 CPU）。对比 delay() 或 for(i=0;i<100000;i++); 的忙等方式，vTaskDelay 让出 CPU 给其他任务使用
  • portTICK_PERIOD_MS 是 tick 周期（通常为 10ms），用 time_ms / portTICK_PERIOD_MS 将毫秒转为 tick 数

编程技巧：

  • 善用 ESP_LOGW（警告）和 ESP_LOGE（错误）区分日志级别，不要所有日志都用 printf 或 ESP_LOGI
  • 在 menuconfig 中可以设置 CONFIG_LOG_DEFAULT_LEVEL，发布固件时设为 WARN 避免日志占用太多串口带宽
  • Ctrl+] 退出 monitor 是 Vim 风格的快捷键，也可以按 Ctrl+T 然后 ? 查看 monitor 帮助
