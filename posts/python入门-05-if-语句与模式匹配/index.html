5. if 语句与模式匹配

5.1 条件测试

📝 条件判断：if/elif/else 做分支选择。关键点：①条件表达式结果只有 True/False；②真值规则——None、0、""、[]、{} 被视为 False，其余为 True；③短路求值——A and B 若 A 假则不算 B；④== 比较值，is 比较对象身份。== 和 = 混用是经典错误。

📚 知识扩展

  • 真值测试：以下值被视为 False：None、0、0.0、""、[]、()、{}、set()。其余都是 True。这就是 if list: 检查非空的原理。
  • 短路求值：A and B 中，若 A 为 False 则 B 不会被计算。A or B 中，若 A 为 True 则 B 不会被计算。
  • match/case vs if-elif：match 更适合解构复杂数据结构（元组、列表、字典、类实例），if-elif 更适合简单的范围比较。
  • 链式比较：18 <= age < 65 比 age >= 18 and age < 65 更直观。
