HCIA 高频考点速记

考点一句话记住
@State 特性变量变化自动刷新 UI
@Prop vs @Link@Prop 单向只读，@Link 双向绑定（用 $）
生命周期顺序aboutToAppear → onPageShow → onPageHide → aboutToDisappear
Stage 模型基于 UIAbility，onCreate 只调一次
Navigation 路由pushPath 跳转，pop 返回，clear 清空
Preferences键值对存储，get/put/flush
LazyForEach长列表懒加载，cachedCount 缓存项
module.json5注册 Ability、声明权限

4.5 HCIP-HarmonyOS 认证备考

项目内容
考试代码H14-321
考试名称HCIP-HarmonyOS Application Developer V1.0
新增考点分布式能力、性能优化、系统能力、NDK、AI
对应笔记高级-01（分布式）、高级-02（性能）、高级-03（系统能力/AI）

HCIP 新增高频考点：

  • 分布式软总线的三种能力（发现/传输/调度）
  • LazyForEach 性能优化参数（cachedCount）
  • 权限级别分类（normal/system_basic/system_core）
  • DevEco Profiler 各维度分析
  • N-API 与 NAPI 的区别
