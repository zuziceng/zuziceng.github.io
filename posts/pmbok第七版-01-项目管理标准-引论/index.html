01-项目管理标准-引论

项目管理标准的目的、关键术语、受众

2026年7月5日PMBOK第七版3分钟阅读

1.1 《项目管理标准》是干嘛的？

一句话：把项目管理这件事”标准化”，让全世界有统一语言。

不管你是做软件、建大楼、还是搞活动——项目管理的底层逻辑是相通的。这个标准就是把这些通用的逻辑总结出来。

英: The Standard for Project Management provides a foundation for understanding project management and how it enables intended outcomes.

📌 最容易混淆的几组概念

① 成果 (Outcome) vs 可交付物 (Deliverable)

第七版最大的转变：不再只看”交了什么”，更看”带来了什么改变”。

可交付物成果
字面交出来的东西带来的变化
例子开发了一套考勤系统HR 效率提升了 50%
考核是否按时按预算交付是否创造了价值

举例子：

客户要你做一个”员工培训平台”（可交付物），但客户真正需要的是”员工技能提升 30%“（成果）。 如果你只交付了平台但没人用，那就是”交付了可交付物，但没有实现成果”。

② 项目 (Project) vs 运营 (Operations)

项目运营
性质临时性，有始有终持续性，重复做
目标创造独一无二的结果维持业务正常运转
结束目标达成，项目就结束了不会结束
例子建一栋楼、开发一个 App交物业费、维护服务器

记住：项目有开始有结束，运营一直在做。 “开发一个App”是项目，“运维这个App”是运营。

③ 价值 (Value)

价值 = 这个东西有什么用 / 对谁有用 / 值不值得

不同人对价值的看法不同：

  • 客户说价值 = 好用、解决问题
  • 老板说价值 = 赚钱、省钱
  • 社会说价值 = 环保、公益
  • 团队说价值 = 成长、成就感

英: Value is subjective. Different stakeholders perceive value differently.

术语中文专业释义说人话English
项目管理 (Project Management)将知识、技能、工具与技术应用于项目活动以满足需求用科学的方法把项目做成Project Management
项目经理 (Project Manager)由执行组织委派，领导项目团队实现目标被组织指派、带队实现目标的人Project Manager

干系人 (Stakeholder)能影响项目决策、活动或结果的个人、群体或组织能影响项目或被项目影响的人Stakeholder
价值交付系统 (Value Delivery System)组织为实现战略目标而构建的、整合了项目组合、项目集、项目和运营的框架为了创造价值而搭建的一整套机制Value Delivery System

1.3 这本书写给谁看？

不是只有”项目经理”才需要看！以下人都能从中受益：

  • ✅ 项目经理 — 这是你的”行业圣经”
  • ✅ 项目团队成员 — 理解你做的事在整个项目中的位置
  • ✅ 产品经理/产品负责人 — 第七版特别强调了产品管理
  • ✅ 项目发起人 (Sponsor) — 知道怎么支持项目
  • ✅ PMO 成员 — 建立组织级项目管理标准
  • ✅ 高管/决策层 — 理解项目怎么创造价值
  • ✅ 学生/转行者 — 入门项目管理的首选教材

英: This standard provides fundamental reference for stakeholders involved in projects.
